## 二、正文（主推版本，可直接粘贴）

按《员工电脑自查流程》做电脑自查时，一直有几个不太顺手的地方：一是要先装 Everything，新同事电脑上往往没有；二是敏感词和后缀得一个一个手工敲进去搜，来回切换十几次；三是**信创电脑上根本没有 Everything 可用**，这部分同事只能靠手工翻文件夹；四是查完没有留痕，说不清"我确实查过了"。

业余时间借助 Claude Code 写了个小工具，把这套流程固化了下来：解压双击，浏览器自动打开操作页面，扫描 → 勾选 → 移入"待删除暂存区" → 人工确认 → 删除并导出自查报告。**Windows、信创（麒麟/统信）、Mac 都能跑，绿色免安装、不需要管理员权限、全程不联网。**

几个我自己比较在意的设计：

- **不直接删文件**。命中的文件先移到"待删除暂存区"并记好原始路径，你逐个核对完再删；发现误判可以一键还原回原位置。最终"删除"也只是移入系统回收站，还有最后一道后悔药。
- **误判尽量不打扰你**。只有"文件名含敏感词 + 位于桌面/下载/文档等常用目录"双命中的才算高风险、默认勾选；单纯是个 PDF 的不会默认选中，避免把工作资料一锅端。
- **规则可以自己补**。默认敏感词（身份证、合同、执照、流水、房产、征信、手机等）写在 rules.json 里，扫描前还能临时加几个自己业务上的词，只对本次生效。
- **图片可以点开预览**，证件照这类不用挨个打开确认；也可以直接"打开文件"或"打开所在文件夹"。
- **自动生成自查报告**（HTML），扫了哪些范围、发现多少、删了多少、什么时候做的，都在里面，可以留档备查。

工具本身只在本机跑，不联网、不上传、不收集任何数据，报告也只存在自己电脑上。

**最后是重要提醒**：
1. 这是个人业余时间做的自用小工具，**不是官方工具**，请以所在单位合规和科技部门的正式要求为准；
2. 涉及移动和删除文件，**请务必先看清暂存区清单再确认删除**，不要一路点到底；
3. 工具只按文件名和后缀做匹配，**不能保证覆盖全部敏感文件**，不能替代人工判断，更不能作为"已完成自查"的免责依据；
4. 部分电脑装有终端安全管控软件，首次运行可能被拦截或提示，这种情况请先咨询科技部门，不要自行绕过。

## 四、发帖前待你补充/确认的三件事

### 1. 获取方式怎么写

同事那篇给的是 GitHub 地址 + 百度网盘分流。你的仓库已开源在 GitHub（`banker-tools-sensitive-info-selfcheck`），但**内网大概率访问不了 GitHub**，建议：

- 主推：内网共享盘或内部附件上传（如平台支持附件），这也最符合"内网工具内网分发"的合规习惯；
- 备选：附上 GitHub 地址供能上外网的同事下载和提 issue。

**需要你判断**：贴 GitHub 地址会关联到你的个人 GitHub 账号。仓库本身没有任何单位名称、没有真实数据，是通用工具，但要不要在内网帖子里公开这个关联，你自己权衡。如果不想，就只走内网分发。

### 2. 截图要不要在 Windows 上重拍（建议重拍）

现有截图是我在 Mac 演示环境跑出来的，路径显示为 `/tmp/演示电脑/桌面/...`，而**看帖的同事绝大多数用 Windows**，看到 `C:\Users\...` 会更有代入感。另外自查报告截图里带了演示机器的主机名，重拍能一并解决。

重拍很简单：在 Windows 上解压运行，随便建几个测试文件（如"张三身份证正面.jpg"），走一遍流程截图即可。如果你想省事，直接用现有这套也能说明问题。

### 3. 发帖前先报备（强烈建议）

你这个工具和同事那个基金工具有一点本质不同：**它会移动和删除电脑上的文件，而且直接涉及"客户敏感信息"这个话题**。在全行平台公开发布前，建议先跟本行合规/科技部门打个招呼，主要是两件事：

- 工具会被终端管控软件（天擎/EDR 类）拦截，报备加白名单本来就要走；
- 由科技或合规背书之后再发，帖子的份量和安全性都完全不同，也避免被理解成"个人擅自发布可删除文件的程序"。

如果暂时不方便报备，一个更稳妥的过渡方案：**先在本部门/本支行小范围试用**，帖子里也把"个人自用、非官方工具"写在前面（正文已经这么写了）。
