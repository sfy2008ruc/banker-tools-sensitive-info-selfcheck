# 电脑敏感文件自查工具（selfcheck）

一款**绿色便携、完全离线**的本机敏感文件自查与清理工具。面向需要定期清理电脑中留存的客户敏感资料（证件照片、合同、流水等扫描件与文档）的场景，例如金融机构一线人员的合规自查。

单个可执行文件，解压即用：双击启动 → 浏览器自动打开操作页面 → 扫描 → 勾选 → 移入暂存区 → 人工确认删除 → 生成自查报告。

## 特性

- **零安装、零依赖**：Go 标准库实现，单文件二进制，无需管理员权限，不写注册表
- **全平台**：Windows 10、macOS（Intel/Apple Silicon 通用）、Linux x64 / ARM64（含麒麟、统信等信创系统）
- **规则可配置**：敏感词、后缀、热点目录、排除目录均在 `rules.json` 中外置，可由管理方统一更新；扫描时还可临时输入补充搜索词（仅单次生效）
- **误删兜底**：命中文件先移入"待删除暂存区"并记录台账（原路径、命中规则），支持一键还原；确认删除也只进系统回收站
- **辅助甄别**：结果按风险分级（高风险预勾选）、时间/后缀筛选、图片点击预览缩略图、一键打开文件或所在文件夹
- **合规留痕**：每次自查生成 HTML 报告（扫描范围、处理明细、时间戳），仅存本机
- **安全设计**：服务仅监听 `127.0.0.1`，随机端口 + 一次性 token，文件操作严格限定在扫描结果与台账范围内，全程无任何出站网络请求

## 构建

需要 Go 1.21+：

```bash
go build ./cmd/selfcheck        # 本机版本
./build/build.sh                # 一键产出全平台发布包（build/out/）
```

测试：

```bash
go test ./...
```

## 使用

1. 解压发布包到任意位置
2. 启动：Windows 双击 `selfcheck.exe`；macOS 双击 `启动自查工具.command`；Linux 双击 `start.sh`
3. 按页面提示完成扫描、勾选、暂存、确认删除，最后导出自查报告
4. 暂存区与报告位于用户主目录下的 `待删除文件区/`

## 目录结构

```
cmd/selfcheck/     入口：端口/token、调起浏览器、优雅退出
internal/rules/    规则加载与内置默认规则
internal/scanner/  并发扫描与命中判定
internal/quarantine/ 暂存区、manifest 台账、还原与回收站删除
internal/report/   自查报告生成
internal/server/   本机 HTTP API（token/同源校验、路径边界）
internal/platform/ 平台差异（路径展开、回收站、打开文件）
web/dist/          前端单文件页面（go:embed 内嵌，兼容 Chrome 90）
```

设计文档见 [spec-version1.md](spec-version1.md)、[plan.md](plan.md)、[tasks.md](tasks.md)。

## 说明

- 本工具仅在本机运行，不采集、不上传任何数据
- 删除操作均可通过暂存区还原或系统回收站找回，但请在确认无误后再执行删除
- `rules.json` 中的默认敏感词仅为示例，请按自身场景调整
